STEP 1 : 게임 유저 관리 시스템

STEP 2 : 요구사항 작성
1. 사용자는 게임에 가입할 수 있다(insert)
2. 사용자마다 고유 아이디를 가져야 한다(primary)
3. 사용자는 정보 변경이 가능하다(update)
4. 사용자는 회원탈퇴할 수 있다(delete)
5. 관리자는 게임유저 명단을 볼 수 있다(select)

STEP 3 : 데이터 설계
User Entity
- id (INT)
- username (TEXT)
- password (TEXT)
- email (TEXT)

Admin Entity
- admin_id (INT)
- admin_username (TEXT)
- admin_password (TEXT)

STEP 4 : SQL 작성

	id bigserial,
	username TEXT,
	password TEXT,
	email TEXT
