실습 과제

데이터 요구 분석 명세서

1. 여행 상품 관리
새로운 여행상품을 계속 개발하고 있다
여행사는 각 여행상품에 대한 정보를 저장한다
각 여행상품은 고유번호로 구분되어야 한다
하나의 상품은 하나 이상의 관광 일정 정보를 포함해야한다

2. 예약 관리
고객이 여행상품을 예약한 날짜와 예약금 납부 여부를 관리한다
각 예약은 고유예약번호로 식별 가능해야한다
고객이 예약을 취소할 경우 취소 사유를 저장해야한다
예약 상태는 "예약 완료", "결제 대기", "예약 취소", "이용 완료"로 구분해야한다

3. 고객 관리
고객 등급은 '일반', '우수', '최우수' 로 구분
여행사는 고객의 정보를 저장해야한다
고객별로 예약 상태를 조회할수있어야한다
고객의 이용 실적에 따라 고객 등급이 정해진다

4. 직원 관리
현재 약 30명의 직원이 근무하고 있다
각 직원은 직원번호로 식별 가능해야한다
직원별 시스템 접근 권한을 구분해 관리해야한다
직원의 상태를 재직, 휴직, 퇴사 등으로 구분해야한다

트랜잭션 요구 분석 명세서

1. 여행 상품 관리
직원은 자신이 담당하는 여행상품을 검색할 수 있다
직원은 여행상품의 정보를 수정할 수 있다
직원은 신규 상품을 등록할 수 있다
직원은 조건에 따라 상품을 조회할 수 있다

2. 예약 관리
고객이 여행상품의 예약 일자 정보를 삽입한다
고객이 상품을 선택하면 정보를 저장한다
예약번호를 기준으로 예약 상태를 변경한다
직원은 조건에 따라 예약 목록을 조회할 수 있다

3. 고객 관리
탈퇴한 고객 정보를 삭제한다
신규 가입한 고객 정보를 등록한다
기존 고객 정보를 수정한다
특정 고객의 이용 이력을 조회한다

4. 직원 관리
직원은 자신의 휴대폰 정보를 변경할 수 있다
재직중인 직원의 명단을 조회한다ㅌ`
기존 직원 정보를 수정한다
특정 직원의 담당 업무를 조회한다
